# IDM-Theme — PLAN.md
_Updated 2026-11-11_

## Goal
A modern dark look for IDM that people can download and use, shared on GitHub + corenetbase.com, and possibly offered to Tonec (IDM's maker).

## Architecture
- `idm-ui/` Electron app (main.js = registry reader + IDM launcher, renderer.js = UI, preload.js = IPC bridge).
- `UIUXMonster-Dark/` toolbar theme generated by `generate_theme.py`; `install.ps1` copies it into IDM's Toolbar folder.
- `docs/` = project web page (bilingual, GoatCounter + support.js).

## Decisions
- 2026-11-11: window buttons like Windows (minimize, maximize, close on the right), not macOS dots.
- 2026-11-11: publish publicly on GitHub and the site; idea to send it to IDM.

## Roadmap
- Possible Windhawk mod to recolour IDM's own window (list, header, progress) — offered, not decided.
